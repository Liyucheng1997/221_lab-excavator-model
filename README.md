# 挖掘机驾驶培训模拟器

用 Three.js 做的 20 吨级液压反铲(CAT 320 / 小松 PC200 量级)驾驶培训模拟器。目标是**玩完就会开挖掘机**:尺寸、操纵方式、操作规程和安全规矩都照真机来。

```bash
npm install
npm run dev      # → http://localhost:5173
```

不依赖任何外部素材:模型全部程序化建模,贴图用 canvas 现画,声音用 WebAudio 现合成,离线可跑。

---

## 玩法

| 模式 | 内容 |
|---|---|
| **驾校课程** | 10 节课,按真人学挖机的顺序:绕机检查 → 启动与熄火 → 认识手柄 → 斗齿点位 → 行走与转向 → 挖一斗土 → 挖沟 → 装车 → 平整场地 → 上下坡。每节课有教练分步指导(可开语音),做错了会告诉你为什么不能这么干。 |
| **考证模拟** | 对照挖掘机操作证实操考核:起动 → S 弯场地驾驶 → 定点触球 → 挖掘装车 → 平整 → 收车熄火。百分制扣分,80 分合格;挖断管线、撞人、倾翻、撞车头直接不合格。 |
| **工地任务** | 基坑开挖装车(自卸车排队进场,中途有施工员从机器后面经过)、管沟开挖(横穿一条在役燃气管,两侧 1 m 内禁止机械开挖)、场地平整。按质量和安全结算工钱。 |
| **自由练习** | 土堆 + 自卸车 + 标杆,没有考核。 |

成绩、星级、最佳分数存在浏览器本地。

## 操作

### 两根先导手柄(工作装置)

国内绝大多数机器是 **ISO 手法**,美标是 **SAE 手法**(动臂和斗杆对调),设置里或按 `P` 切换。

| | 左手柄 前后 `W` `S` | 左手柄 左右 `A` `D` | 右手柄 前后 `I` `K` | 右手柄 左右 `J` `L` |
|---|---|---|---|---|
| **ISO** | 斗杆 伸 / 收 | 回转 左 / 右 | 动臂 降 / 升 | 铲斗 收 / 卸 |
| **SAE** | 动臂 降 / 升 | 回转 左 / 右 | 斗杆 伸 / 收 | 铲斗 收 / 卸 |

键盘是开关量,所以**按住越久推得越多**(约 0.45 秒推到底),按住 `Shift` 最多只推 1/3,用来微操。接游戏手柄最好:摇杆就是先导手柄,可以真正地半推。

### 行走

`R` / `F` 左履带前进 / 后退,`T` / `G` 右履带前进 / 后退。两根同推直行,只推一根绕另一条履带转,一推一拉原地转。
"前进"是朝引导轮的方向(驱动轮在后)——**上车转过 180° 之后,推杆前进车会往你背后走**,这是真机新手最容易出事的地方。

### 驾驶室开关

| 键 | 作用 |
|---|---|
| `E` | 钥匙:按一下 OFF → ON(仪表自检);在 ON 时**按住** = START 打火;运转时按一下 = 熄火 |
| `Q` | 先导安全锁杆:抬起 = 锁定(液压切断);放下 = 解锁。**锁杆没锁,起动机不转**(中位起动保护) |
| `空格` | 喇叭:起步前鸣笛;装完车鸣笛放车;有人进作业半径时鸣笛示警 |
| `-` `+` | 油门旋钮 1~10 档 |
| `V` | 行走 龟 / 兔 档 |
| `M` | 作业模式 P 重载 / E 经济 / L 精细 |
| `U` / `B` | 自动怠速 / 工作灯 |

### 视角

`C` 切换:驾驶室(默认,拖动鼠标转头、滚轮缩放、双击回正)/ 环视 / 跟随 / 侧视 / 俯视。
`Tab` 打开右上角的**侧视小窗** —— 屏幕没有纵深感,真人坐在驾驶室里是靠双眼判断远近的,这个小窗用来弥补。

其他:`Enter` 交卷/验收,`Esc` 暂停,`H` 按键说明,`X` 一键收拢(仅自由练习)。

游戏手柄:左右摇杆 = 两根先导手柄;LT/RT 左右履带前进,LB/RB 后退;A 喇叭,B 锁杆,X 龟兔档,Y 视角,Back 钥匙,Start 暂停,十字键上下调油门。

## 哪些地方是照真机做的

### 尺寸与工作范围

按 20 吨级真机标定:动臂 5.7 m、斗杆 2.9 m、1.0 m³ 铲斗,履带轨距 2.2 m、600 mm 履带板、节距 0.19 m,尾部回转半径 2.75 m,配重离地 1.09 m,驾驶室顶离地约 3.0 m。

`npm run linkage` 复核:最大挖掘半径 10.5 m、深度 6.4 m、高度 9.5 m;动臂缸和斗杆缸的行程比都是 0.76,铲斗缸 0.62,全程单调、不碰机构死点。铰点位置是用脚本在设计空间里搜出来的,不是拍脑袋定的。

### 模型

- **行走装置**:驱动轮(带齿)、引导轮、7 个支重轮、2 个托链轮;链节 + 销套 + 三筋履带板一节一节沿"外公切线 + 圆弧"的真实闭合路径运动,绕轮时呈折线;各轮转角由履带走过的路程换算,不打滑。还有行走马达、X 形车架、回转支承和行驶方向标。
- **上车**:配重外缘贴着回转半径,发动机舱带百叶检修门、排气管、空滤帽,右前的工具箱、燃油箱(带油位计)、液压油箱(带观察窗),扶手、后视镜、后视摄像头、警示灯(运转时旋转闪烁)。
- **驾驶室**:立柱、前上/前下窗、门、雨刮、顶灯;内饰有座椅、左右操纵台和先导手柄、安全锁杆、行走杆和踏板、油门旋钮、钥匙、灭火器,以及一块会实时显示转速、水温、燃油、档位、锁杆状态的仪表屏。手柄、锁杆、行走杆会跟着你的输入动。
- **工作装置**:焊接箱型动臂和斗杆(翼缘板、加强板、轴套、销轴挡板),四根油缸(缸筒长度固定、活塞杆真的伸缩),铲斗四连杆(摇臂 + H 连杆),沿动臂/斗杆的钢管,以及随姿态实时弯曲的液压软管。
- **铲斗**:C 形斗壳、侧刃、刃口板、5 个齿座 + 斗齿、斗底耐磨条、耳板。

> 铲斗外形有个坑值得记一笔:真实反铲斗的斗口在"斗齿指向"的**顺时针一侧**——收斗到底、斗齿指向机身时斗口朝天,土才兜得住。画成镜像的话机构照样能动,但满收斗时斗口朝地,一提土就撒光。

### 液压与动力

- 手柄 → 先导 → 主阀 → **流量** → 油缸速度。关节角速度 = 油缸速度 ÷ |dL/dθ|,所以同样的手柄行程,在不同姿态下转速不一样。
- 油缸速度按真机循环时间反推(动臂举升约 3 s,斗杆收约 3 s,铲斗收约 2.4 s),回转约 11.5 rpm。
- 两台主泵的总流量有限:三个动作一起推到底就分不够,复合动作会变慢。
- 油门档位决定转速,转速决定泵流量;作业模式 P/E/L 限制流量;手柄回中 4 秒自动怠速。
- 油缸顶到头还在推 → **溢流阀尖叫**、发动机掉转速(憋缸)。

### 土

- 铲斗按侧面外轮廓的"下包络线"切土:斗子朝着斗口张开的方向走,扫过的土从斗口进斗;斗背、斗底压到的土只能压下去几厘米,再深就顶住。
- 切土有速率上限:插得太深就憋住,一斗土大约要拖 2~4 秒才装满;原状土比松土难挖一倍。
- **动臂下压不是铲**:斗齿能扎进去一截,再压就把车撑起来(撑车)。
- 土会不会撒,看斗口法线还朝不朝上;斗子埋在土里时不撒;满斗回转起停太猛,冒尖的部分会甩出去。
- 撒出来的土一块块落下,落在车厢里就进车,落在外面就堆在地上。土堆有休止角(约 36°),陡了会塌。

### 整机

- 回转有惯量:斗里有土、斗杆伸得越远越难启停,要**提前松手**。
- 整机贴合地形俯仰侧倾;坡太陡履带打滑爬不上去;行走时铲斗顶到地面就走不动。
- **倾翻**:实时算整机重心(下车、上车、配重、动臂、斗杆、铲斗、斗里的土)在履带支撑范围里的投影。满斗侧向伸远还稳,再多挂几吨就会翻。
- **碰撞**:铲斗会撞到自己的驾驶室和履带、撞到自卸车、撞倒路锥和标杆;配重回转会扫到人。

### 规矩(扣分项都附带原因)

起步不鸣笛、满斗从自卸车驾驶室上方过、卸料太高砸车、撞车、憋缸不松手、高转速直接熄火(涡轮没冷却)、连续起动过久、冷车重载、作业半径内有人还继续作业、坡上用兔子档/转向/回转、弃土离沟边太近、离机不锁先导杆……

## 代码结构

```
src/
  config.js        整机尺寸、液压、质量、地形参数(所有"魔法数字"都在这)
  linkage.js       二维运动学:油缸长度、四连杆位置分析
  model/
    geo.js         建模工具:挤出、倒角盒、按材质合并、履带闭合路径、随动软管
    materials.js   材质与程序化贴图(油漆磨损、铸钢、防滑板、贴花)
    undercarriage.js  行走装置
    upper.js       上部回转体
    cab.js         驾驶室外壳 + 内饰 + 仪表屏
    front.js       动臂、斗杆、铲斗、油缸、连杆、管路
  excavator.js     模型装配 + 每帧姿态
  machine.js       整机仿真:发动机、液压、土壤、撑车、倾翻、碰撞
  terrain.js       可挖掘高度场(0.25 m 一格,增量上传 GPU)
  truck.js         自卸车:模型、自动进出场、车厢里的土
  world.js         天空、工地环境、道具(路锥、标杆、放线、燃气管、工人)
  fx.js            落土颗粒、扬尘、排气烟
  input.js         键盘/手柄 → 手柄行程,ISO/SAE 手法映射
  audio.js         发动机、液压、溢流阀、履带、喇叭、报警器(全部合成)
  camera.js        五种视角 + 画中画侧视
  game.js          关卡框架:步骤、安全监控、扣分、存档
  scenarios.js     课程、考证、工地任务的内容
  ui.js            菜单、HUD、成绩单
  main.js          装配 + 主循环
tools/
  linkage-check.mjs   复核油缸行程、单调性、工作范围
  linkage-solve.mjs   搜索铲斗四连杆参数
```

坐标约定:工作平面是二维的 `(x=前, y=上)`,整机朝 `+X`,回转绕 `Y`,各关节绕 `Z`。按右手系 `右 = 前 × 上 = +Z`,所以驾驶室(在左侧)的 z 是负的。回转角按 Three.js 惯例逆时针(向左)为正。
