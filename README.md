# 挖掘机操作模拟器

用 Three.js 做的 20 吨级液压反铲(CAT 320 / 小松 PC200 量级)模拟器,目标是**照着真机的操作方式来学开挖掘机**,而不是做一个"能挖土的游戏"。

```bash
npm install
npm run dev      # → http://localhost:5173
```

---

## 怎么操作

挖掘机只有四个基本动作:**回转、动臂、斗杆、铲斗**,分给两根手柄。真机上有个 ISO/SAE 转换阀,能把动臂和斗杆在两只手之间对调,本模拟器两种手法都支持(按 `P` 切换)。

| | 左手柄 前后 | 左手柄 左右 | 右手柄 前后 | 右手柄 左右 |
|---|---|---|---|---|
| **ISO**(日本标准,国内绝大多数机器) | 斗杆 伸/收 | 回转 左/右 | 动臂 降/升 | 铲斗 收/卸 |
| **SAE**(美标) | 动臂 降/升 | 回转 左/右 | 斗杆 伸/收 | 铲斗 收/卸 |

两种手法有个共同直觉:**手柄推离身体,工作装置就往外/往下走**。

### 键盘

| 键 | 作用 |
|---|---|
| `W` `A` `S` `D` | 左手柄 |
| `I` `J` `K` `L` 或方向键 | 右手柄 |
| `R` / `F` | 左履带 前进 / 后退 |
| `T` / `G` | 右履带 前进 / 后退 |
| `P` | 切换 ISO / SAE |
| `-` `+` | 油门 1~10 档 |
| `C` | 换视角(环视 / 驾驶室 / 跟随 / 侧视) |
| `X` | 收拢成行进姿态 |
| `N` | 下一关 |
| `H` | 操作说明 |

行走那两根杆是**分别控制左右履带**的,和真机一样:两根同推 = 直行,只推一根 = 绕着另一条履带转,一推一拉 = 原地打转。

### 手柄

接上游戏手柄体验最接近真机:左右摇杆就是两根先导手柄,`LT`/`RT` 控制左右履带前进,`LB`/`RB` 后退。

---

## 关卡

按真人学挖机的顺序排的:先分别认识四个动作 → 练复合动作的落点 → 挖满一斗 → 挖出规矩的沟 → 装车 → 行走 → 平整场地。

平整是最后一关也是最难的,真机上这就是区分新手和老手的基本功。

---

## 为了"真实"做了哪些事

这个项目的重点不在画面,在于**机器的行为对不对**。

### 1. 手柄控制的是流量,不是角度

真挖掘机的手柄 → 先导压力 → 主阀开度 → **流量** → 油缸速度。手柄给的是油缸速度,不是关节角度。所以:

```
关节角速度 = 油缸速度 ÷ |dL/dθ|
```

`|dL/dθ|` 随姿态变化,于是同样的手柄行程,在不同姿态下关节转速不一样 —— 新手常问"怎么快到头就变慢了",原因就在这里。本模拟器如实照搬了这条链路(`machine.js`),`dL/dθ` 每帧数值求导。

油门也是真的有用:泵排量跟着转速走,油门小则所有动作都慢。平整场地时把油门调小反而更好控制,这和真机一致。

### 2. 铲斗是四连杆推的,不是直接转的

真机的铲斗油缸不直接推铲斗,而是经过**摇臂(power link)+ 连杆(idler link)**组成的四连杆机构放大转角。这套机构的位置分析在 `linkage.js`,每帧解两次圆-圆相交。

机构参数不是拍脑袋定的,是用 `tools/linkage-solve.mjs` 在设计空间里搜出来的,硬约束包括:

- 转角行程 175°(真机 175~185°)
- 油缸 1.78 → 2.87 m,**行程比 0.62**(真机 0.4~0.7)
- 全程**严格单调**,不碰机构死点 —— 否则手柄推到一半铲斗会自己反向
- **伸缸 = 收斗** —— 挖掘的重活走全缸径,靠伸出发力,和真机一致
- 摇臂始终在斗杆背面之上,不穿模

> 这里有个坑值得记一笔:四连杆有两个装配支(open / crossed),**两支的转向相反**,选错了就变成"伸缸=卸料"。另外容易想反的是转向 —— 斗齿从"朝下"收到"朝后上"走的是**顺时针**的 150° 近路,不是逆时针的 210°(总行程才 175°,根本转不过去)。

`npm run linkage` 可以随时复核三根油缸的行程和单调性。

### 3. 土会不会撒,判的是斗口法线

不是"斗角超过某个阈值就掉土",而是算**斗口平面的法线还朝不朝上**:

```js
mouthUp = sin(动臂角 + 斗杆角 + 铲斗角 + 斗口法线安装角)
```

法线的竖直分量掉到阈值以下,土就开始往外撒,翻得越过分撒得越快。所以你必须像真机一样,挖完立刻收斗兜住,回转过程中也得保持住 —— 边挖边低头是装不满斗的。

### 4. 回转有惯量

上车十几吨重,起停都得"荡"一下,松手还会滑一段。这是装车对不准的头号原因,也是为什么真机手回转要**提前松手**。

### 5. 其他

- **油缸真的在伸缩**,两端铰点跟着关节走;缸筒长度固定,活塞杆滑出滑进,任何姿态都还露着一截杆。动臂缸两根、斗杆缸一根、铲斗缸一根 —— 和 20 吨级真机的配置一致。
- **履带板逐块沿闭合路径运动**,节距 0.21m(真机 ≈0.19m),左右分开驱动,所以差速转向时能看见两条履带走得不一样快。
- **整机贴合地形**:四角采高度,定出高度 + 俯仰 + 侧倾。
- 挖出来的土**有休止角**,堆陡了会自然塌方。
- 发动机声是 WebAudio 现合成的,基频取点火频率(转速/60×2),**憋缸会掉转速** —— 真机手是听着声音判断斗子插太深的。

工作范围复核(`npm run linkage`):最大挖掘半径 10.6 m、挖掘深度 6.0 m,和 20 吨级真机(9.5~10.0 / 6.5~6.7)基本对得上。

## 代码结构

```
src/
  config.js     整机尺寸与调校参数(所有"魔法数字"都在这)
  linkage.js    二维运动学:油缸长度、四连杆位置分析
  excavator.js  三维模型 + 运动学装配
  machine.js    仿真状态:流量→油缸→关节、回转惯量、履带差速、挖/撒
  terrain.js    可挖掘高度场
  input.js      双手柄 + ISO/SAE 手法映射(键盘 / 游戏手柄)
  tasks.js      教学关卡
  world.js      场景、自卸车、标志物
  hud.js        界面
  audio.js      引擎与液压声(纯合成,无音频文件)
  main.js       装配 + 主循环
tools/
  linkage-check.mjs   复核三根油缸的行程 / 单调性 / 工作范围
  linkage-solve.mjs   搜索铲斗四连杆参数
```

坐标约定贯穿全工程:工作平面是二维的 `(x=前, y=上)`,整机朝 `+X`,回转绕 `Y`,各关节绕 `Z`。按右手系 `右 = 前 × 上 = +Z`,所以驾驶室(在左侧)的 z 是负的。

不依赖任何外部素材,所有纹理都是 canvas 现画的,离线可跑。
